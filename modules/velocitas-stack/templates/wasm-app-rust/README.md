# SimVehicleApp WebAssembly app (Rust)

Generated by SimVehicleApp for the `wasm` target (ADR-0061). The app is a `wasm32-wasip1` module run by
`sv-wasm-host`, which connects it to the KUKSA databroker (`kuksa.val.v2`) and MQTT.

```bash
cargo build --manifest-path app/Cargo.toml --release --target wasm32-wasip1 --offline
sv-wasm-host --precompile app/target/wasm32-wasip1/release/app.wasm app.cwasm
sv-wasm-host --test app.cwasm app/tests/generated/cases.json      # generated test cases
sv-wasm-host app.cwasm app/src/generated/sv-app.json               # run on the vehicle stack
```

- `app/src/generated/` and `app/tests/generated/` are written by SynCode (the crate builds after the first SynCode);
  `app/src/user_hooks.rs` is yours.
