# SimVehicleApp WebAssembly app (C++)

Generated by SimVehicleApp for the `wasm` target (ADR-0061). The app is a `wasm32-wasip1` module run by
`sv-wasm-host`, which connects it to the KUKSA databroker (`kuksa.val.v2`) and MQTT.

```bash
cmake -S app -B build -DCMAKE_TOOLCHAIN_FILE=$WASI_SDK_PATH/share/cmake/wasi-sdk.cmake -DCMAKE_BUILD_TYPE=Release
cmake --build build
sv-wasm-host --precompile build/app.wasm build/app.cwasm
sv-wasm-host --test build/app.cwasm app/tests/generated/cases.json      # generated test cases
sv-wasm-host build/app.cwasm app/src/generated/sv-app.json               # run on the vehicle stack
```

- `app/src/generated/` and `app/tests/generated/` are written by SynCode; `app/src/user/` is yours.
- Toolchain: wasi-sdk-34, nlohmann/json 3.11; the image `toolchain-wasm` has both.
