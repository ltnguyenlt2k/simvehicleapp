### Nội dung

1. Đăng ký tài khoản trên studio hiện có.
2. Kéo thả 16 block robot.
3. Cấu hình điều kiện RSS (`Robot.PowerSystem…`, marker), động tác, toạ độ, log.
4. Nối 23 cổng có tên, gồm nhánh lỗi, nhánh hết giờ và cạnh quay lui của vòng lặp.
5. Kiểm tra OK.
6. Build: artifact `sha256:54bd3826…`.
7. Deploy lên `ros-sim` (dog1 · DISARMED · courtyard).
8. Mở Robot Zoo ở tab mới.
9. Start có xác nhận. Robot thật trong sim chạy theo thứ tự: Arm → chờ thấy marker → BOW → LIFT_FRONT_LEFT → JUMP → tuần tra 2 vòng GoTo (1,0) ↔ (0,3, 0) → log hoàn tất → Disarm.
10. Panel Chạy trong studio hiện kết quả từng lệnh kèm request id.
