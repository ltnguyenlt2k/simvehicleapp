Overlay xoá các file đó; tasks/launch SimVehicleApp đặt ở mức user (gdb qua `webfreak.debug`).
2. **`scripts/sv build` và nightly dựng toolchain trước `contracts`** (stage agent cần image contracts) — sửa thứ tự (`fc49737`).
3. **Orchestrator lưu graph bằng `jsonb` ⇒ khoá bị sắp lại**: so sánh graph export bằng deep-equal, không so byte (graph vẫn là cùng WorkflowGraph).
4. **Khoá công khai license qua biến môi trường nhiều dòng** khó truyền qua `.env` ⇒ nhận cả PEM base64 (`ca109ed`).
6. **`ide-cpp` luôn "unhealthy"**: image IDE kế thừa HEALTHCHECK của toolchain (gọi agent :4210, IDE không chạy agent) ⇒ IDE có HEALTHCHECK riêng trên `/healthz` của code-server.
