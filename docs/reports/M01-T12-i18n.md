# M01-T12 — Kiểm tra i18n (Q8: ngôn ngữ UI VI/EN)

Ngày: 2026-10-03 · Người kiểm: Claude Code · Baseline: Sim v0.7.13 (`modules/simvehicleapp-studio`)

## Câu hỏi
Q8 ([15](../../analysis/15-risks-and-open-questions.md)): UI dùng VI hay EN; Sim có sẵn i18n để thêm tiếng Việt không?

## Kiểm tra đã chạy
```bash
grep -n '"next-intl"\|"i18next"\|"react-intl"\|"@lingui' apps/sim/package.json package.json   # không có
grep -rn "useTranslation\|useTranslations" --include=*.tsx apps/sim/app                         # không có
grep -n "<html" apps/sim/app/layout.tsx                                                         # lang='en'
cat .github/workflows/i18n.yml                                                                  # Lingo.dev chỉ dịch apps/docs
```

## Kết quả
- `apps/sim` **không có framework i18n**; mọi chuỗi UI hard-code tiếng Anh (vd 87 đoạn text JSX dạng `>Label text<` chỉ riêng `app/workspace`). `<html lang='en'>` cố định.
- i18n duy nhất của upstream là workflow Lingo.dev dịch **app docs** (`apps/docs`, đã gỡ ở M01-T04) — không áp dụng cho studio.
- Thêm tiếng Việt cho toàn bộ studio = đưa vào thư viện i18n + trích hàng nghìn chuỗi của Sim ⇒ trái ADR-0008 (sửa file Sim tối thiểu) và không thuộc phạm vi M1.

## Quyết định cho M1 (không đổi kiến trúc)
1. **UI mặc định tiếng Anh** (giữ nguyên Sim) — trả lời Q8 cho MVP.
2. Chuỗi UI của phần SimVehicleApp tự viết được **gom vào config/hằng số** (vd `components/sv/sv-config.ts`: action bar, dock, banner an toàn) để có thể nối vào i18n sau mà không phải tìm rải rác.
3. Hỗ trợ tiếng Việt (nếu PO cần) ⇒ ADR riêng khi lập kế hoạch (đề xuất M11+/M14): chọn thư viện (vd `next-intl`), phạm vi chỉ màn hình SimVehicleApp hay cả Sim, và cách giữ đồng bộ khi cherry-pick upstream.
