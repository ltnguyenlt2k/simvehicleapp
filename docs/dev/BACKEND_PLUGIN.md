# BACKEND_PLUGIN — một backend ngôn ngữ (`compiler-code-<lang>`)

Backend biến IR thành mã nguồn của vehicle app Velocitas. Tham chiếu: [analysis/07](../../analysis/07-codegen-backends.md),
ADR-0020 (contract backend), ADR-0021 (runtime), ADR-0022 (tests sinh ra), ADR-0040/0041. Mẫu thực tế:
`modules/compiler-code-cpp/` (generator TypeScript + runtime C++ + template overlay).

## 1. Contract HTTP (không được phá)
| Endpoint | Ý nghĩa |
|---|---|
| `GET /capabilities` | nội dung `backend.yaml`: ngôn ngữ, opcode hỗ trợ, phiên bản runtime |
| `POST /generate` | IR[] (+ scenario) ⇒ `GeneratedFileSet` (contract `generated-fileset.v1`): files + sha256 + `ownedRoots` + `manifestFragment` + source map |
| `GET /runtime/files`, `GET /template-overlay/files` | runtime vendored vào project, overlay lên template Velocitas |
| `/healthz`, `/version`, `/metrics` | qua `service-kit` |

Compiler (S7) đọc `/capabilities` của các backend trong `SV_BACKENDS` (`cpp=http://codegen-cpp:4110,…`): opcode không có
⇒ `OPCODE_UNSUPPORTED_BY_BACKEND` trước khi sinh.

## 2. Luật generator
1. Thuần và tất định: không filesystem ngoài package, không mạng, không thời gian/ngẫu nhiên — chạy hai lần cùng sha.
   Container chạy `read_only`, `cap_drop: ALL`, chỉ trên mạng nội bộ `sv-codegen` (không egress).
2. Chỉ sinh trong `ownedRoots` (`app/src/generated/`, `app/tests/generated/`); AppManifest qua `manifestFragment`.
   Chỉ service `workspace` ghi đĩa.
3. Header mọi file: `Generated by SimVehicleApp compiler-code-<lang> <ver> — DO NOT EDIT. irHash=<…>`.
4. Chuỗi người dùng qua hàm escape của ngôn ngữ (`cppString`); identifier qua `sanitizeIdent()` + hash; fuzz test.
5. Mỗi node có yield ⇒ hàm/bước riêng; mọi lời gọi runtime mang `nodeId`; source map node ⇒ dòng (lỗi build map về khối).
6. Không bao giờ gọi LLM.

## 3. Luật runtime
- Ngữ nghĩa ADR-0012: strand một luồng, yield points, chính sách trigger, huỷ, loop guard.
- Chỉ lớp adapter (C++: `VelocitasVehicleAccess`, `VelocitasPubSub`) gọi Velocitas SDK; phần còn lại test với
  MockVehicle + VirtualClock.
- Trace: một dòng `SVTRACE {"v":1,…}` ra stdout (contract `trace-event`), mức theo `SV_TRACE_LEVEL` (chỉ hạ được).
- Runtime có version riêng (`runtime/VERSION`) và được vendor vào project lúc init.

## 4. Kiểm thử bắt buộc
| Mức | Nội dung | Lệnh (C++) |
|---|---|---|
| Golden | mã sinh cho GW-A…G không đổi (diff = 0), tất định | `cd generator && bun test` |
| P1 conformance | mọi case `fixtures/conformance/*` + golden build với runtime, chạy trên mock = expected | `generator/conformance/conformance.sh` |
| P3 parity | app thật trên KUKSA = trace golden (lưới 10 ms ± 20 ms) | `modules/simvehicleapp-orchestrator/gate/parity-p3.sh` |
| Generated tests | scenario của workflow ⇒ test chạy trong bước `test` của SynCode | qua SynCode |

## 5. Thêm ngôn ngữ mới (checklist analysis/07 §8)
1. Module mới `modules/compiler-code-<lang>/` (generator + runtime + template overlay + `backend.yaml` + `compose.yaml`).
2. Image toolchain `modules/velocitas-stack/toolchain/<lang>` với agent (`/jobs`: init, deps, build, test, run).
3. Thêm vào `SV_BACKENDS` (compiler) và `SV_BACKENDS`/`SV_TOOLCHAINS` (orchestrator) — **không** sửa studio/core/orchestrator.
4. Golden + P1 + P3 phải pass cho mọi golden mà backend khai báo hỗ trợ (ADR-0042 §3).
5. License: dependency qua `scripts/license/scan.sh`; NOTICE của module.
