## 2. Backend Plugin Contract v1 (HTTP)

| Endpoint | Request | Response |
|---|---|---|
| `GET /capabilities` | — | nội dung `backend.yaml` dạng JSON |
| `POST /generate` | `GenerateRequest` | `GeneratedFileSet` hoặc `{diagnostics[]}` (422) |
| `GET /runtime/files` | — | file set của runtime (để workspace vendor vào project) + `runtimeVersion` |
| `GET /template-overlay/files` | — | file set overlay (dùng khi init project) |
| `GET /healthz`, `GET /version` | — | chuẩn module |

```jsonc

{ "project": { "slug": "comfort-app", "appName": "ComfortApp", "language": "cpp",
               "mqttTopicPrefix": "simvehicleapp/comfort-app", "traceLevel": "node" /* off|trigger|node */ },
  "workflows": [ /* IR v1[] đã validate */ ],
  "options": { "emitTests": true } }

// GeneratedFileSet
{ "backend": "cpp@0.1.0", "runtimeVersion": "0.1.0",
  "files": [ { "path": "app/src/generated/workflows/StableOverspeedWarning.cpp", "content": "...", "sha256": "…", "role": "source" } ],
  "ownedRoots": ["app/src/generated/", "app/tests/generated/"],
  "manifestFragment": { "vehicle-signal-interface": { "src": "…vss_rel_4.0.json", "required": [ {"path":"Vehicle.Speed","access":"read"} ], "provided": [] },
                        "pubsub": { "reads": [], "writes": ["simvehicleapp/comfort-app/hmi"] } },
  "sourceMaps": [ { "file": "app/src/generated/workflows/StableOverspeedWarning.cpp", "ranges": [ { "startLine": 12, "endLine": 14, "nodeId": "n2", "blockId": "b2", "workflowId": "wf_7Hk" } ] } ],
  "diagnostics": [] }
```

**Luật bắt buộc cho mọi backend**
1. **Thuần & tất định:** không đọc đĩa ngoài package của nó, không gọi mạng, không timestamp/random trong output. Cùng request ⇒ cùng bytes (test: generate 2 lần, so sha).
2. Chỉ sinh file trong `ownedRoots`; mọi thứ khác (AppManifest) trả dạng *fragment* để workspace merge.
3. Header mọi file: `// Generated by SimVehicleApp compiler-code-cpp 0.1.0 — DO NOT EDIT. irHash=<…>` (không có thời gian).
4. Format ổn định: generator tự format theo `.clang-format` của template (hoặc chạy `clang-format` ở bước verify của toolchain — output đã format sẵn để diff = 0).
5. Không bao giờ gọi LLM (network egress của container bị chặn trong compose: `networks: [internal]`).

## 4. Runtime C++ (`simvehicleapp-runtime-cpp`) — API công khai (v0.1)

```cpp
namespace simvehicleapp::rt {
using Ms = std::chrono::milliseconds;
enum class Policy { Restart, Ignore, Queue, Parallel };
enum class Mode { Any, Rising, Falling, CrossesAbove, CrossesBelow, Becomes };

class IClock { public: virtual int64_t nowMs() const = 0; virtual ~IClock() = default; };
class Strand;              // event loop 1 thread: post(fn), postAt(ms, fn) → TimerId, cancel(TimerId)
class Tracer;              // emit "SVTRACE {json}" lines; level off|trigger|node

template <class T> class Signal {               // bọc velocitas::TypedDataPoint<T>
public: const std::string& path() const; std::optional<T> cached() const; };

class Ctx {                                      // ngữ cảnh 1 run instance
public:
  const RunInfo& run() const;                   // runId, workflow, trigger value
  bool cancelled() const;
  template <class T> void read(Signal<T>&, const char* node, std::function<void(Ctx&, T)> k,
                               std::function<void(Ctx&, const Error&)> onErr = {});
  template <class T> void write(Signal<T>&, T v, const char* node, Cont k, ErrCont onErr = {});
  void writeMany(Batch, const char* node, Cont k, ErrCont onErr = {});
  void wait(Ms d, const char* node, Cont k);
  void waitUntil(Pred p, Ms timeout, const char* node, Cont ok, Cont timeout);
  void stableFor(Pred p, Ms d, const char* node, Cont stable, Cont broken = {});
  void publish(const std::string& topic, const std::string& payload, const char* node);
  void log(Level, const std::string& msg, const char* node);
  template <class T> T trace(const char* node, T value);   // trả lại value, ghi trace
  void stop(StopScope);
};

class Runtime {
public:
  template <class T> Signal<T>& signal(velocitas::TypedDataPoint<T>& dp);  // đăng ký + cache
  void onAppStart(const char* node, Entry e);
  template <class T> void onSignalChanged(Signal<T>&, ChangeSpec<T>, Policy, const char* node, Entry e);
  void onTimer(Ms interval, Ms initialDelay, Policy, const char* node, Entry e);
  void onMqtt(const std::string& topic, Policy, const char* node, std::function<void(Ctx&, const std::string&)>);
  template <class T> StateVar<T>& state(const char* name, T initial);
};

class AppBase : public velocitas::VehicleApp {   // host
protected: void onStart() final;  virtual void bindWorkflows(Runtime&) = 0;
};
namespace testing { class MockVehicle; class VirtualClock; class ScenarioPlayer; }
}
```
- Mọi callback SDK → `strand.post`. Không `->await()` trên strand (chỉ dùng `onResult/onError` của `AsyncResult`).
- Subscription gộp theo path (1 `subscribeDataPoints` / path) + fan-out cho nhiều trigger.
- **Cancel:** mỗi run có token; `wait/stableFor/waitUntil` đăng ký timer gắn token → cancel huỷ timer, continuation không bao giờ chạy.
- **Policy** thực thi trong `Runtime::dispatch()` (bảng ở [05 §3.2](05-blocks-and-execution-model.md#32-chính-sách-đồng-thời-concurrency-policy-của-trigger)).
- **Trace** line: `SVTRACE {"v":1,"ts":…,"app":"ComfortApp","wf":"wf_7Hk","run":42,"node":"n2","ev":"enter"}`.
- Runtime có **test suite riêng** (gtest + MockVehicle), build bằng Conan 2 độc lập (không cần generator).

## 5. Chiến lược sinh code C++ (tóm tắt ADR-0022)
- **Continuation-passing**: mỗi node có yield → hàm `step_<nodeId>(Ctx&)`; node thuần (logic/math) inline thành biểu thức.
- Biểu thức `$expr` → biểu thức C++ với kiểu tường minh (`static_cast<float>(…)`), không macro.
- Identifier: `PascalCase(workflow name)` + hậu tố hash 4 ký tự nếu trùng; biến `snake_case_`; không bao giờ dùng tên người dùng thô trong code (sanitize `[A-Za-z0-9_]`, chuỗi người dùng chỉ xuất hiện trong string literal đã escape).
- String literal escape qua hàm duy nhất `cppString()` (chống injection).
- Emitter theo opcode, đăng ký trong bảng — thêm opcode = thêm 1 emitter + golden test.

## 6. `compiler-code-python` (M12)
- Template `vehicle-app-python-template@e7082f7`, SDK `velocitas-sdk==0.15.7`, model tại `gen/vehicle_model`.
- Runtime `simvehicleapp_runtime` (asyncio): `Runtime`, `Ctx` với `await c.read()`, `await c.wait()`, `c.stable_for()`; policy qua `asyncio.Task.cancel()`.
- Sinh `app/src/generated/*.py` + `app/src/main.py` (overlay) gọi `SimVehicleApp(vehicle).run()`.
- Toolchain: `toolchain-python` image `FROM ghcr.io/eclipse-velocitas/devcontainer-base-images/python:<pin>`.

## 7. `compiler-code-rust` (M13 — feasibility trước)
- Không có Velocitas Rust SDK ⇒ backend cung cấp **template riêng** `vehicle-app-rust-template` (AppManifest v3 giữ nguyên để tương thích tooling, `Cargo.toml`, `Dockerfile`).
- Client: `kuksa-rust-sdk 0.2.2` (tonic) — dùng `sdv.databroker.v1` để đồng nhất hành vi với C++/Python, hoặc `kuksa.val.v2` + provider.
- Runtime `simvehicleapp-runtime-rs` (tokio: `select!`, `CancellationToken`), vehicle model: sinh typed struct từ VSS trong chính generator (vì model-generator không hỗ trợ Rust).
- Gate feasibility: GW-A chạy được & parity pass.

## 8. Thêm một ngôn ngữ mới — checklist
1. Tạo repo `compiler-code-<lang>` theo cấu trúc §1, implement contract §2.
2. Viết runtime `<lang>` với đủ semantics [05 §3](05-blocks-and-execution-model.md#3-ngữ-nghĩa-thực-thi-execution-semantics) + trace format.
3. Thêm toolchain `toolchain-<lang>` trong `velocitas-stack` (hoặc image riêng) implement Toolchain API.
4. Thêm IDE image `ide-<lang>` (tuỳ chọn).
5. Pass `conformance/` + parity cho toàn bộ golden mà backend khai báo hỗ trợ.
6. Thêm `compose.lang-<lang>.yaml` + mục trong `simvehicleapp.lock.yaml`.
**Không** sửa studio/core/orchestrator (orchestrator tự khám phá backend qua `BACKENDS=cpp=http://codegen-cpp:4110,…`).
