# `compiler-code-<lang>` — generator + runtime

Tham chiếu: `analysis/07-codegen-backends.md`, ADR-0020/0021/0022/0040/0041.

## Contract (không được phá)
`GET /capabilities` (= backend.yaml) · `POST /generate` (IR[] → GeneratedFileSet) · `GET /runtime/files` · `GET /template-overlay/files` · `/healthz` · `/version`.

## Luật generator
1. Thuần & tất định: không fs ngoài package, không mạng, không thời gian/random; chạy 2 lần ⇒ cùng sha.
2. Chỉ sinh trong `ownedRoots` (`app/src/generated/`, `app/tests/generated/`); AppManifest trả `manifestFragment`.
3. Header: `Generated by SimVehicleApp compiler-code-<lang> <ver> — DO NOT EDIT. irHash=<…>`.
4. Chuỗi người dùng qua `cppString()/pyString()`; identifier qua `sanitizeIdent()` + hash suffix.
5. Mỗi node yield → hàm/step riêng; mọi lời gọi runtime truyền `nodeId`; `CodeWriter` ghi source map.
6. Opcode chưa có emitter ⇒ không liệt kê trong `backend.yaml.opcodes`.
7. Không bao giờ gọi LLM.

## Luật runtime
- Ngữ nghĩa theo ADR-0012 (strand 1 luồng, yield points, policies restart/ignore/queue/parallel, cancel, loop guard).
- Chỉ lớp adapter (`VelocitasVehicleAccess`) gọi SDK; phần còn lại test được với MockVehicle + VirtualClock.
- Trace: một dòng `SVTRACE {"v":1,…}` ra stdout, level từ `SV_TRACE_LEVEL`.
- Runtime có version riêng (`runtime/VERSION`), vendored vào project (`app/src/simvehicleapp-runtime/`).

## Quy trình thêm emitter/opcode
1. Emitter + unit test chuỗi sinh ra. 2. Golden update (`--update-golden`, review diff). 3. Runtime hỗ trợ (nếu cần) + conformance. 4. Cập nhật `backend.yaml.opcodes`. 5. Compile golden trong toolchain image.

## Thêm ngôn ngữ mới
Checklist `analysis/07-codegen-backends.md` §8 — **không** sửa studio/core/orchestrator; chỉ thêm repo + toolchain + compose + `SV_BACKENDS`.
